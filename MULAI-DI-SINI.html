Tampilan yang baru.

Paket ini membawa data terbaru dari ZIP lama: 33 transaksi, 5 anggaran, dan 2 sumber uang. Frontend React sudah dibangun, jadi Node.js tidak diperlukan untuk menjalankan aplikasi lokal.

Cara menjalankan di Windows

  1. Ekstrak seluruh ZIP ke folder pilihan, misalnya D:\Belajar\Arus.
  2. Pastikan Python 3.10+ terpasang beserta launcher.
  3. Klik dua kali MULAI-WINDOWS.bat. Pertama kali perlu internet untuk memasang dependency.
  4. Setelah terminal menampilkan server aktif, buka http://127.0.0.1:8765.
  5. Masuk dengan username demo dan password demo123456.

Biarkan terminal terbuka selama menggunakan aplikasi. Ini halaman panduan, bukan aplikasi; data tampil melalui alamat server di atas.

Gmail & hosting

Pengingat email siap dikonfigurasi melalui Pengaturan → Profil & Gmail. Email nyata membutuhkan akun pengirim. Baca docs/GMAIL.md dan docs/HOSTING.md memakai Notepad atau VS Code.

Untuk hosting gratis tersedia Docker, adapter PostgreSQL dan gateway Gmail HTTPS. Ganti password awal sebelum aplikasi dipublikasikan. Jangan upload folder data, cadangan atau .env ke repository publik.

Tentang akun lama

ZIP sumber ternyata berisi username magangmedan. Di paket baru, login salinan kerja disesuaikan menjadi demo sesuai permintaan; data keuangan tidak diganti. Kedua database asli tetap tersedia di original-backups.
